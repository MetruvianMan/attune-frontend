# Chat Tab - Visual Guide for Parents

## What You'll See

### Opening the Chat Tab

When you tap the 💬 Chat tab, you'll see:

1. **Your child's profile** at the top (photo + name)
2. **Clean, spacious conversation area** - no clutter
3. **Simple input box** at the bottom with a blue send button
4. **Subtle metadata** showing documents and data connected

### Starting a Conversation

#### Suggested Questions (First Time)
When there's no conversation yet, you'll see gentle suggestions:
- "Verbal strengths"
- "Sensory differences"  
- "School accommodations"
- "Sleep patterns"
- "Emotional regulation"
- "Common triggers"

**Look & Feel**: Soft blue pills, no harsh borders, inviting taps

### Your Messages

When you type a question, it appears:
- **On the right side** (like you're used to)
- **With a subtle sage green line** on the left edge
- **In slightly smaller, gray text** (16px) so it doesn't compete
- **With a timestamp** below in tiny text

**Example**:
```
                              What are his verbal strengths?    |
                                                        9:23 PM  |
                                                                 |
                                                                 |
```
*(Imagine a subtle green line on the left)*

### Attune's Responses

When Attune responds, you'll see:
- **"ATTUNE" label** in small, uppercase blue letters
- **Clean response text** at 17px - easy to read
- **No bubble or box** around the text - just the words
- **Structured sections** when relevant:
  - Bold headers for topics
  - Bullet points for lists
  - Paragraphs with breathing room

**Example**:
```
ATTUNE

Based on your logged events, here are his verbal strengths:

Strong Communication Skills
- Uses complex sentences (logged 15 times this month)
- Asks clarifying questions when confused
- Expresses emotions verbally

Social Language
He adapts his language based on context...
```

### Spacing & Feel

**What's Different from Other Apps**:
- **More space between messages** - Each exchange has room to breathe (32px gaps)
- **No colored bubbles** - Clean, distraction-free reading
- **Larger text** - 17px instead of typical 15px chat apps
- **Better line spacing** - Easy to track lines when tired

**It Should Feel Like**:
- Reading a letter from a specialist
- Sitting across from an expert who knows your child
- Having breathing room to think

**It Should NOT Feel Like**:
- Slack or Teams messaging
- Texting with a friend
- A dashboard full of data

### Bottom Controls

At the bottom of the screen:

**Left side**:
- "+ New" button - Start fresh conversation

**Center**:
- "📄 X docs · 📊 Data connected" - Shows what Attune knows

**Right side**:
- "📚 Saved" - View past conversations
- "💾 Save" - Archive this conversation (appears after first message)

**Look & Feel**: Small, subtle text that doesn't compete with the conversation

### Input Area

**The text box where you type**:
- Larger than typical chat (48px tall)
- Rounded pill shape
- Soft shadow (not a border)
- Placeholder: "Ask about patterns, strengths, supports, or behaviors..."

**Send button**:
- Blue circle with → arrow
- 48px diameter
- Soft shadow makes it float

**Feel**: Inviting, premium, encourages you to ask questions

### Saved Chats View

Tap "📚 Saved" to see past conversations:
- **Clean white cards** with soft shadows
- **Date shown in small uppercase** (e.g., "JUN 23, 2026")
- **Conversation title** from first question
- **Preview text** showing first lines
- **X button** on right to delete

**Example Card**:
```
┌──────────────────────────────────────┐
│ What are his verbal strengths?       │
│ JUN 23, 2026                         │
│                                      │
│ Based on your logged events, here... │
└──────────────────────────────────────┘
```

### While Attune Is Thinking

When processing your question:
- "ATTUNE" label appears
- Spinning indicator + "Thinking..." text
- Blue accent color

**Time**: Usually 2-5 seconds depending on data

### Empty States

**No profile yet**:
- Large 👤 icon
- "No profile selected"
- "Create a child profile in the Profile tab to get started."

**Offline**:
- Large 📡 icon
- "Offline"
- "Conversations require an internet connection..."

**No saved chats**:
- Large 💬 icon
- "No saved chats yet"
- "Save a conversation to view it here"

### What Parents Notice

#### Positive Reactions We Expect:
- "This feels calmer than other apps"
- "I can actually read the responses easily"
- "It doesn't feel like I'm texting - it feels more serious"
- "The spacing helps me focus"
- "I like that it gets out of my way"

#### What Might Take Getting Used To:
- "Where are the message bubbles?" → That's intentional for cleaner focus
- "The responses are longer on screen" → Yes, because spacing increased for readability
- "My messages look different than Attune's" → Yes, to create hierarchy (you vs. expert)

### Accessibility

**For Parents Who**:
- **Are tired** → Large text (17px), generous spacing helps
- **Have vision challenges** → Text meets WCAG AA contrast standards
- **Use larger system fonts** → Text will scale with iOS settings
- **Have motor challenges** → All buttons are ≥48px, easy to tap

### Technical Notes

**Nothing Changed About**:
- How the AI works
- What data gets used
- How conversations save
- Security or privacy
- Internet requirements

**Only Changed**:
- How it looks
- How easy it is to read
- How calm it feels
- How premium the design is

### Comparison to Before

| Before | After |
|--------|-------|
| Felt like Slack messaging | Feels like expert consultation |
| Colored bubble backgrounds | Clean, borderless text |
| 15px text | 17px text (easier to read) |
| Tight spacing | Generous breathing room |
| Walls of text | Structured sections |
| Busy bottom bar | Subtle controls |

### Design Goals Achieved

1. ✅ **Less like enterprise software** - No harsh borders, busy layouts
2. ✅ **More like trusted companion** - Warm typography, calm spacing
3. ✅ **Easy to scan when tired** - Large text, clear headers, structure
4. ✅ **Premium, not cheap** - Thoughtful details, shadows, polish
5. ✅ **Gets out of the way** - Conversation is focal point, not UI
